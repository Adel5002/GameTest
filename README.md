# 🌙 Страж Снов

Залипательный **merge tower defense** для Android.
Ночью из шкафа лезут кошмары и ползут к кровати малыша. Защищают его игрушки:
доставай их из сундука, **сливай одинаковые** в более сильные и не дай малышу проснуться.

Подробный геймдизайн и разбор того, на чём держится «залипательность», — в [DESIGN.md](DESIGN.md).

## Как играть

1. Жми **«Достать игрушку»** — на коврик падает случайная игрушка из твоей колоды.
2. **Перетащи две одинаковые** (тип + уровень) друг на друга → получишь случайную игрушку уровнем выше.
3. Кнопки над «Достать» — **усиление типа**: качают все игрушки этого типа до конца ночи.
4. Каждая 5-я волна — **босс**. Тапай по **падающим звёздам** — там подарки.
5. За ночь получаешь ⭐ → открываешь сундуки → новые игрушки и прокачка → ещё дальше в следующую ночь.

## Как установить на телефон

### Вариант 1 — готовый APK (GitHub Actions)
Каждый push собирает APK автоматически:
**Actions → Android APK → последний запуск → Artifacts → `strazh-snov-apk`**.
Скачай zip, распакуй, скинь `strazh-snov.apk` на телефон и установи
(разреши «Установку из неизвестных источников»).

### Вариант 2 — собрать самому
Нужны Node 22+, JDK 21 и Android SDK (проще всего — Android Studio).

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```
Или `npx cap open android` — откроется Android Studio, жми ▶ Run на подключённом телефоне.

### Вариант 3 — в браузере
```bash
npm run serve   # http://localhost:8080
```
Открой с телефона в той же Wi-Fi сети (http://IP-компьютера:8080) → «Добавить на главный экран».

## Структура

```
www/                 # сама игра (чистый HTML5 Canvas + JS, без сборки)
  js/data.js         # баланс: игрушки, враги, боссы, задания, сундуки
  js/audio.js        # синтезированные звуки и колыбельная (Web Audio)
  js/profile.js      # сохранение, мета-прогресс, ежедневки
  js/game.js         # движок: поле, волны, бой, эффекты, отрисовка
  js/ui.js           # меню, HUD, коллекция, сундуки, модалки
android/             # Capacitor-обёртка для Android
assets/              # исходники иконки и сплэша
```

Баланс крутится в `www/js/data.js` (`baseHP`, статы игрушек, цены).
Иконки пересобираются командой `npm run assets`.
